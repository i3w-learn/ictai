Board window: test report

27 November 2026. Tried on the Mac, in the browser stand-in, against a fresh test server. Not tried on Windows.

What was built

A second window of the same app for a board that is plugged into the Server PC as a second screen. Staff press Open on the board in the console. The board then shows only the lesson: the video, the book's page or the whiteboard. The controls stay on the Server PC screen. The teacher can write on the board by touch.

No new install is needed, and nothing changes for students.

Result

All 16 checks passed on real screens for the teacher, the Super Admin and the student.
Not tried: the real second window on Windows. In the test browser the board window is a second browser tab. The native part that opens the window, puts it on the second screen and makes it full screen compiles and its tests pass, but it has never been run on a Windows PC with a board.
