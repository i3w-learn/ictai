Marathi for teachers and admins: test report

26 November 2026. Tried on the Mac, in the browser stand-in, against a fresh test server. Not tried on Windows.

What was checked

With the top bar set to मराठी, a script opened every tab as Super Admin (Today, Teach, Videos, Reports, School, System) and as a teacher (the same without System), and listed every line on the screen that still had English words and no Marathi.

Result: no English sentence is left on any tab. What stays in English is data the school typed: the school name, people's names, period names, PC names, subject names.

The teacher walk also opened New quiz, Ask AI, Plan a lesson, Make a quiz with AI and the Whiteboard: all in Marathi.

With the top bar set back to English, the screens read exactly as before. The student screens still work in Marathi.

The automatic tests pass three times in a row (128 tests). One of them reads the source of every screen and fails if any sentence has no Marathi line; it now covers 869 sentences.

Not tried, and what to run on Windows

Nothing here was tried on a real Windows PC. Windows must draw the Marathi letters with its own font, so run Step 4a of docs/windows-test-guide.md, which now also covers the Server PC.

The AI pages were only seen with no AI kit installed (the "AI is not installed" message). The pages after a real AI answer were not seen.

A Marathi speaker has not yet read the wording. The words were written by an AI model, in plain school Marathi.

Messages that come from the server (for example "Wrong password") are still in English. That is a separate piece of work on the server.
